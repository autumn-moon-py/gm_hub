# 回归关注点

> rebuilt_at: 2026-05-08

## 1. 启动与路由
- 直接运行主程序是否进入主窗口。
- 传入 `output` 或 `multi_window` 参数是否正确进入输出窗口。
- 传入 `.gmh` 路径是否正确打开项目。

## 2. 保存链路
- `保存`、`另存为项目`、`Ctrl+S` 是否都能落盘。
- `.gmh` 与 `.json` 是否都能被重新读取。

## 3. 输出合同
- 编辑主窗口内容后，输出窗口是否同步刷新。
- 输出窗口双击图层后，主窗口选择是否回显。
- `outputScaleMode` 变化后，输出布局是否符合预期。

## 4. 图层树与舞台交互
- 图层树多选、编组、解组、拖拽排序是否仍然正确。
- root 节点是否仍保持逻辑存在但 UI 隐藏。

## 5. 音频与骰子
- 音频导入、切换、播放/暂停、循环、重新关联是否正常。
- 命运骰加值输入与流消息同步是否正常。

## 6. Windows 宿主与文件关联
- 安装器生成是否成功。
- 安装后 `.gmh` 双击是否正常。
- 非安装态运行时文件关联回退是否不破坏开发体验。
