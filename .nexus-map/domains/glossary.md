# 术语表

## 主窗口
主持端编辑窗口，对应 `GmHubApp` + `MainShell`。

## 输出窗口
玩家可见窗口，对应 `OutputWindowApp`。

## root 节点
项目逻辑根节点，`id = 'root'`，保留在数据模型中但默认不在图层树 UI 中展示。

## 图层树
从 `project.root.children` 开始展示的层级视图，支持选择、多选、编组、拖拽排序。

## `sync_render`
主窗口发给输出窗口的同步方法名，承载渲染列表、流消息、画布尺寸和输出缩放模式。

## `select_node`
输出窗口发回主窗口的选择方法名，用于把双击命中的节点同步回主持端。

## `.gmh`
项目默认文件扩展名；底层是 gzip 压缩后的 JSON。

## 安装态 / 非安装态
安装态指通过安装器运行；非安装态指直接从开发构建目录运行，此时 `main.cpp` 会尝试回退注册文件关联。
