# 笔记区空白与图层撤回设计

> 日期：2026-05-08

## 目标

- 缩小窗口时，笔记区不再因为全屏按钮预留而浪费过多右侧空间。
- 主窗口支持 `Ctrl+Z` 撤回图层域与画布直接操作。

## 设计

- 笔记区继续保留右下角全屏按钮，但将文本区域避让从固定大块预留改为更小的局部预留，优先保证编辑宽度。
- `ProjectStore` 增加图层历史快照栈，仅记录图层树与选择状态；每次图层相关变更前压入快照，撤回时恢复快照并复用现有刷新链路。
- `Ctrl+Z` 只作用于图层域与画布直接操作，不覆盖笔记、音频、骰子等运行态。

## 覆盖范围

- 位置、缩放、旋转、显隐、锁定、重命名
- 新增/删除图层
- 编组/解组
- 图层拖拽排序
- 文字层内容修改

## 不在本次范围

- `Ctrl+Y` 重做
- 笔记、音频、骰子、输出窗口状态撤回
